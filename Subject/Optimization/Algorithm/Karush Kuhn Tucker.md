## 概述
1. 用于判断一个解是否为约束优化问题最优解的一阶必要条件
2. 将拉格朗日乘子法推广到了包含不等式约束的更一般情况
## 引出
### 问题（标准型）
1. 最小化 $f(x)$
2. 约束于 $g_i(x) \le 0$, for $i=1, \dots, k$ (不等式约束)
3. 约束于 $h_j(x) = 0$, for $j=1, \dots, m$ (等式约束)
4. 如果非标准型，只需在下面公式中将 $g_i(x)-a \le 0$ 中 $g_i(x)-a$ 视为整体即可
### 不等式约束
不等式约束 $g_i(x) \le 0$ 有两种情况，KKT 条件需要一种开关机制，来自动处理这两种情况
#### 无效约束
1. 最优解 $x^*$ 位于可行域的内部，即 $g_i(x^*) < 0$
2. 有没有这个约束，最优解都是 $x^*$，此时不应该考虑这个约束的梯度
#### 有效约束
1. 最优解 $x^*$ 位于可行域的边界上，即 $g_i(x^*) = 0$
2. 这个约束 $g_i$ 就像一个等式约束一样，限制了 $x^*$ 的取值，此时必须考虑这个约束的梯度
## KKT 条件
### 广义拉格朗日函数
$$\mathcal{L}(x, \mu, \lambda) = f(x) + \sum_{i=1}^k \mu_i g_i(x) + \sum_{j=1}^m \lambda_j h_j(x)$$
一个解 $x^*$ 要成为最优解，必须存在一组乘数 $\mu^*$ 和 $\lambda^*$，使得它们共同满足以下四个条件
### 平稳性
$$\nabla f(x^*) + \sum_{i=1}^k \mu_i^* \nabla g_i(x^*) + \sum_{j=1}^m \lambda_j^* \nabla h_j(x^*) = 0$$
1. 在最优点 $x^*$，拉格朗日函数对 $x$ 的梯度必须为零
2. 这和拉格朗日乘数法的几何意义完全相同
### 原始可行性
$$g_i(x^*) \le 0, for i=1, \dots, k$$
$$h_j(x^*) = 0, for j=1, \dots, m$$
最优解 $x^*$ 必须满足所有原始的约束条件
### 互补松弛性
$$\mu_i^* \cdot g_i(x^*) = 0, for i=1, \dots, k$$
每一个不等式约束 $g_i$ 和它对应的乘数 $\mu_i^*$ 的乘积必须为零
1. 情况 A (无效约束)：如果 $g_i(x^*) < 0$，那么为了使乘积为 0，必须有 $\mu_i^* = 0$。
2. 情况 B (有效约束)：如果 $g_i(x^*) = 0$，那么乘积已经是 0，此时 $\mu_i^*$ 可以为任意值（具体值由“平稳性”条件决定）
### 对偶可行性
$$\mu_i^* \ge 0, for i=1, \dots, k$$
所有不等式约束 $g_i \le 0$ 对应的乘数 $\mu_i^*$ 必须非负
1. KKT 条件中最核心的一点，几何直观为在最优点 $x^*$，目标函数的下降方向 $(-\nabla f)$ 必须指向可行域之外
2. 因为梯度指向可行域之内，就还可以沿着这个方向走一点，使 $f$ 下降，同时仍在可行域内
## 充要分析
### KKT 是必要条件
对于任意一个非线性优化问题，如果 $x^*$ 是一个局部最优解，并且 $x^*$ 满足某些正则性条件（比如 LICQ，即有效约束的梯度线性无关），那么一定存在 $\mu^*$ 和 $\lambda^*$ 使得 KKT 条件成立
### KKT 也是充分条件
1. 如果原问题是凸优化问题（即 $f(x)$ 和 $g_i(x)$ 是凸函数， $h_j(x)$ 是仿射函数），那么 KKT 条件就是充分必要条件
2. 意味着对于凸优化问题，只要找到了一个满足 KKT 条件的解 $(x^*, \mu^*, \lambda^*)$，那么 $x^*$ 必定是全局最优解。
