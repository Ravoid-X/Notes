## 优先级别
通常通过优化标志来控制，这些标志定义了编译器应该应用的优化深度和种类
### -O0
1. 无优化，默认级别
2. 用于快速编译和方便调试，编译时间最短，执行速度最慢。
### -O1
基本优化，侧重于减小程序体积和编译时间，进行一些简单、安全的优化
### -O2
推荐优化，应用大多数常见的优化技术，如寄存器分配、循环展开等，旨在提高执行速度。
### -O3
激进优化，启用所有 -O2 优化，并添加了更具侵略性、但可能增加代码体积的优化（如函数内联、矢量化）
### -Os/Oz
侧重于最小化最终可执行文件的体积，常用于嵌入式系统
# 核心优化技术
## 消除冗余计算
### 常量折叠
在编译时计算出常量表达式的结果，而不是在运行时计算
```
// 源代码
int a = 5 * 20 + 3; 
// 优化后 (编译时计算结果)
int a = 103;
```
### 公共子表达式消除
识别并消除多次出现的相同表达式，只计算一次结果并将其存储在寄存器或临时变量中
```
// 源代码
int a = (x * y) + z;
int b = w + (x * y);
// 优化后
int temp = x * y; // 只计算一次
int a = temp + z;
int b = w + temp;
```
## 循环优化
### 循环展开
复制循环体内部的代码，以减少循环的迭代次数和检查条件、自增等操作的开销
```
// 源代码
for (int i = 0; i < 100; ++i) { array[i] = i; }
// 优化后 (展开 4 次)
for (int i = 0; i < 100; i += 4) {
    array[i] = i;
    array[i+1] = i+1;
    array[i+2] = i+2;
    array[i+3] = i+3;
}
```
### 循环不变代码外提
将循环体内计算结果不依赖于循环变量的表达式，移动到循环外部，只计算一次
```
// 源代码
for (int i = 0; i < N; ++i) {
    array[i] = i * (M + K); // (M + K) 是不变的
}
// 优化后
int temp = M + K;
for (int i = 0; i < N; ++i) {
    array[i] = i * temp;
}
```
## 函数优化与控制流
### 函数内联
1. 将函数调用替换为被调函数的实际代码。
2. 消除了函数调用的运行时开销，并为后续优化（如常量传播）创造了机会。
### 分支裁剪/消除
如果分析确定某个条件语句（if 语句）的结果在编译时是恒定的，将移除整个条件语句和永远不会被执行的代码块
```
// 源代码
const bool DEBUG = false;
if (DEBUG) { print_debug_info(); } // DEBUG 恒为 false
// 优化后
// 整个 if 块被移除
```
### 死代码消除
移除那些对程序输出或状态没有任何影响的代码行或变量
## 寄存器与内存优化
### 寄存器分配
精确地决定哪些变量应该存储在 CPU 寄存器中，并在需要时重新分配这些寄存器，以最小化对较慢的主内存的访问。
### 矢量化
将原本对单个数据元素的操作，转换为使用 CPU 的 SIMD（Single Instruction, Multiple Data）指令，一次处理多个数据元素（例如使用 SSE/AVX 指令），极大地加速了数组操作和循环。
