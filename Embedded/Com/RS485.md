## 概述
1. RS-485 (即 TIA/EIA-485-A) 是一种定义了驱动器和接收器电气特性的物理层标准。
2. 只规范了信号如何在电气上传输（第1层），而没有规范数据的格式、地址、校验等内容（第2层及以上）。
3. 通常所说的“RS-485协议”（例如 Modbus RTU），实际上是运行在 RS-485 物理层之上的上层协议。
## 差分信号
RS-485 之所以能实现长距离（最远1200米）、高抗噪和多点通信，全依赖于差分信号
### 原理
1. 使用两根信号线，通常标记为 A 和 B（或 D+ 和 D-）
2. 传输的不是“信号线相对于地的电压”（如RS-232），而是两根线之间的电压差 ($V_A - V_B$)
### 逻辑状态
1. 逻辑 1：A 线电压低于 B 线电压；逻辑 0：A 线电压高于 B 线电压
2. 接收器：只要能检测到 $\pm 200mV$ 的电压差，就能正确解析数据
3. 驱动器：必须能产生至少 $\pm 1.5V$ 的电压差，以确保在长距离传输后，到达接收端的信号仍大于 $200mV$
### 共模抑制
1. A 线和 B 线是双绞线，靠得很近，干扰信号会同时耦合在两根线上，从而消除
2. 叠加在 A、B 两条线上的相同噪声称为共模噪声
## 多点总线
允许在同一对A/B线上挂载多个设备，驱动器可以将信号发送到总线上，接收器可以从总线上接收信号
### 三态
大多数 RS-485 收发器（如 MAX485）都具有“三态”功能
1. 驱动高电平 (发送 '0')
2. 驱动低电平 (发送 '1')
3. 高阻态 (High-Impedance / Hi-Z)：当设备不发送数据时，会释放总线（进入高阻态），就像断开了与总线的连接一样，这样其他设备才能发送数据。
### 单元负载
标准规定，一个驱动器最多能驱动 32个单元负载 (UL)
1. 标准的收发器（如 MAX485）通常是 1 UL
2. 现在有很多 1/4 UL 甚至 1/8 UL 的收发器，意味着可以在同一总线上连接 128 个或 256 个设备
## 工作模式
### 半双工（最常用）
1. 接线：只用 2 根线 (A 和 B)
2. 工作方式：所有设备共享这对线。在任何时刻，只允许一个设备处于发送状态，其他所有设备必须处于接收状态。
3. 控制：需要一个方向控制信号，通常叫 DE/RE (Driver Enable / Receiver Enable)\
（1）发送时：拉高 DE/RE，驱动器使能，接收器关闭\
（2）接收时：拉低 DE/RE，驱动器高阻，接收器使能
4. 软件必须严格管理 DE/RE 引脚，确保在发送完最后一个 bit 后立即切换回接收状态，否则会丢失响应数据或产生总线冲突
### 全双工
1. 接线：使用 4 根线 (两对 A/B 线，一对用于发送 TX，一对用于接收 RX)。
2. 工作方式：一个主设备的 TX 连接到所有从设备的 RX。所有从设备的 TX 连接到主设备的 RX。
3. 优点：主设备可以同时向从设备广播（发送）并接收来自某个从设备的响应。不需要复杂的 DE/RE 切换。
4. 缺点：需要 4 根线，成本更高
## 硬件实现
### 拓扑结构
必须使用总线型（或菊花链）拓扑，所有设备都直接并联在主干总线上
1. 星型连接会产生大量的信号反射
2. 当信号遇到阻抗不匹配的点（如电缆分支或末端）时，一部分信号会反弹回来，与原始信号叠加，导致波形畸变，使接收器无法识别。
### 终端电阻
1. 终端电阻通常为 120 欧姆
2. 电缆（尤其是双绞线）本身具有一个特性阻抗，通常在 100-120 欧姆。
3. 为了防止信号到达电缆末端时发生反射，必须在末端放置一个与电缆特性阻抗相匹配的电阻，把信号能量吸收掉。
4. 只在总线的最远两端放置
5. 短距离、低速率（如 9600 bps, 10米内）可以不加；长距离、高速率（如 100kbps, 1000米）必须加
### 偏置电阻
1. 问题：当总线空闲时，A、B 线处于高阻态。此时两条线之间的电压差不确定（接近 0 V），可能会在接收器的 $\pm 200mV$ 阈值附近摆动，导致接收器收到一堆无意义的噪声数据，甚至错误的起始位。
2. 在总线上（通常在主设备端或一端）加两个电阻：一个上拉电阻将 A 线拉到 $+5V$ (Vcc)，一个下拉电阻将 B 线拉到 $0V$ (GND)
3. 当总线空闲时，这两个电阻强制 A、B 之间产生一个确定的正电压差（A > B），使总线处于确定的逻辑 '1'（空闲）状态
4. 典型值如 680 欧姆。注意：偏置电阻和终端电阻会共同消耗电流，阻值需要计算，不能太小。
### 地线
1. 允许收发器之间存在一定的“共模电压差”（通常是 -7V 到 +12V）
2. 问题：如果两个设备的地电位差过大（例如，一个 0V，另一个因为接地不良是 50V），这个电压差会远超收发器的承受范围，导致芯片烧毁。
3. 在 A、B 线之外，再拉一根信号地线，将所有设备的 GND 连接在一起，确保它们的地电位基本一致
4. 最好是使用隔离型 RS-485 收发器（如 ISO3082）。这种芯片在逻辑侧和总线侧之间使用光耦或磁耦进行电气隔离，可以承受几千伏的电压差
## 软件协议
### 主从轮询（最常见）
1. Master (主站)：通常是 PLC、工控机或微控制器。
2. Slaves (从站)：通常是传感器、执行器、变频器等。每个从站都有一个唯一的地址。
3. 工作流程\
（1）Master 发送一个请求帧，所有 Slaves 都会收到这个帧\
（2）只有地址为请求帧中设定的设备会解析并回复一个响应帧\
（3）其他所有地址不匹配的设备保持接收状态\
（4）Master 收到响应后，再去轮询下一个设备
### 常见的上层协议
1. Modbus RTU：工业领域的事实标准。定义了功能码、数据格式和 CRC 校验。
2. Profibus-DP：西门子主导的高速工业总线，底层也使用 RS-485。
3. DMX512：专业舞台灯光控制协议。
4. 自定义协议：大量简单的应用会使用自定义格式（如：帧头 + 地址 + 命令 + 数据 + 校验和）。
